# 文档索引

## 阅读顺序建议
1. `docs/ARCHITECTURE.md` - 架构设计与目录结构
2. `docs/DEVELOPMENT.md` - 开发流程与扩展指南
3. `docs/MAINTENANCE.md` - 维护与变更管理
4. `docs/DEPLOYMENT.md` - 部署与发布
5. `docs/MULTI_APP_TEMPLATE.md` - 多应用模板
6. `docs/TROUBLESHOOTING.md` - 常见问题与排查

## 文档列表
- `docs/ARCHITECTURE.md`：整体架构、分层职责、请求链路、模块边界
- `docs/DEVELOPMENT.md`：环境准备、开发规范、添加功能与模块
- `docs/MAINTENANCE.md`：配置与迁移、依赖升级、运维要点
- `docs/DEPLOYMENT.md`：本地/容器/集群部署流程与注意事项
- `docs/MULTI_APP_TEMPLATE.md`：多应用目录与代码模板
- `docs/TROUBLESHOOTING.md`：常见故障与快速诊断

## 文档维护说明
- 文档与代码保持同步，特别是目录结构、配置项与运行命令。
- 变更路由或响应结构后，请同步更新文档并运行 `./scripts/swagger.sh`。
